# Developer Onboarding Overview

Welcome to SmartTouch, an API-driven home interface. You can use this app to manage, and control connected devices such as gates, washing machines, dishwashers, and other smart appliances.

This guide helps developers, administrators, and integrators get from a fresh installation to their first successful API call in minutes.

## What You'll Learn

By the end of this onboarding guide, you will be able to:

* Understand the different SmartTouch user roles and permissions.
* Configure authentication using JSON Web Tokens (JWT).
* Create and manage user accounts for development environments.
* Start the SmartTouch API locally.
* Authenticate and obtain access tokens.
* Discover registered devices.
* Send commands to connected devices.
* Integrate SmartTouch APIs into your applications using Python or other HTTP clients.
* Prepare your environment for production deployment and user management.


## What You'll Build

By completing this onboarding guide, you will:

* Authenticate against the SmartTouch API.
* Retrieve a list of registered devices.
* Send commands to simulated devices.
* Integrate SmartTouch APIs into your applications.
* Understand the security and operational requirements for production deployments.
